# TextUtils - React App

This project is built using React.js.

## 🚀 Features
- Text transformation (uppercase, lowercase, etc.)
- Dark mode
- Responsive UI

## 🛠 Tech Stack
- React.js
- JavaScript (ES6)
- CSS

## 📦 Installation
npm install
npm start
